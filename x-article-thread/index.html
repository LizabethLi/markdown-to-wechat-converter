Know the boundaries

  • X ignores or strips many rich clipboard elements, so visual assets require manual upload.
  • AI thread generation requires your own OpenRouter API key and only runs when requested.
  • X Articles require an eligible X subscription; availability is controlled by X.

Frequently asked questions

Why not copy Mermaid, formulas, and code directly into X?

The X editor does not reliably preserve those clipboard formats. Exporting them as numbered images produces a more predictable publishing workflow.

Is AI required?

No. The page can create a local publishing preview. AI is optional for the recommendation and expanded thread plan.

Where is my OpenRouter key stored?

It is saved in your browser’s local storage and sent only to OpenRouter when you explicitly request translation or X generation.
